FEenabler

Shows client sided scripts into server for other players to see.

TUTORIAL

You have probably came here to enable fe. Well heres the tutorial on how you set it up.

1. Go to roblox.com

2. Once there go to the game you want to enable fe in

3. Then open inspector with F12 and head to network tab.

4. Do Ctrl + R and find replay

5. Then right click replay and select Copy as PowerShell
